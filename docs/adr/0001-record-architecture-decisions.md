# ADR 0001: Record architecture decisions

- Status: Accepted
- Date: 2026-11-18

## Context

Important architecture choices and their reasoning are otherwise easy to lose.

## Decision

Record significant decisions as numbered ADRs using the template in this directory.

## Alternatives rejected

- Relying on commit messages: they do not capture context or rejected options.
- Maintaining one living design document: it obscures how decisions changed over time.

## Consequences

Decisions are reviewable and traceable; authors must maintain a small amount of documentation when choices change.
